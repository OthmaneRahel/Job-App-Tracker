## Diri le setup (juste pour hiba bnisba lik ahiba hit eamrek dertu la creation chi projet angular) 

So deja endek node js

Ouvrez votre terminal et exécutez la commande suivante :
```bash
npm install -g @angular/cli

```

## les etapes l3adiyin dyalna kamlin

apres matkmel l'installation dyal angular diri :
```bash
git pull origin frontend-main
```
Apres dkhli lprojet li pulliiti o diri :
```bash
ng serve
```
